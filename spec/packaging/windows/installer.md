# Per-user Windows installer

`packaging/windows/installer.wxs` is a WiX 4 package built for x64 by the packaging script, with embedded cabinets, Simplified Chinese product wording, Language 2052, UTF-8 codepage 65001 and per-user scope. ProductVersion is supplied by the builder as `0.2.2.1`. The stable UpgradeCode is `1A5791B8-62CD-45BD-AD90-F6D146FC0180`. MajorUpgrade rejects older product versions with a Chinese downgrade message. Windows Installer compares only the first three ProductVersion components; the fourth component is packaging metadata, not an additional downgrade ordering guarantee.

The complete feature installs `openphoto.exe`, `op-mcp.exe`, `README-zh-CN.md` and four license texts from the supplied extracted portable payload to LocalAppDataFolder/Programs/OpenPhoto-zh-CN. License names are LICENSE-MIT, LICENSE-APACHE, SourceSans3-OFL.txt and NotoSansCJK-LICENSE.txt under Licenses. Each component uses an HKCU registry keypath so the installation belongs to the current user. The installer does not rebuild or modify the executable payload.

A non-advertised Start Menu shortcut named OpenPhoto 简体中文版 targets the installed GUI executable with its installation directory as working directory, under the user's OpenPhoto-zh-CN Start Menu folder. Standard Windows Installer registration exposes the package in Apps with an uninstall entry; modification is disabled with ARPNOMODIFY. Uninstallation removes packaged files, registry component values, the shortcut and empty application/license/Start Menu folders, never the shared LocalAppData/Programs directory or arbitrary user data.

There are no custom installation actions, network downloads, services, administrator-scope changes, paid SDK requirements or interactive WiX UI extensions. Double-clicking uses standard Windows Installer progress behavior rather than a custom wizard. The package is unsigned. The About URL identifies the fork's windows-zh-CN branch.
