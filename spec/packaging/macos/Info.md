# macOS bundle metadata

The Simplified Chinese fork uses bundle identifier `com.xinping7841.openphoto.zh-cn` to distinguish it from upstream. Finder displays `OpenPhoto 简体中文版`; the executable and icon resource names remain `openphoto` and `OpenPhoto`. Development region and declared localization are `zh_CN`. The deployment target remains macOS 11.0; build scripts replace version placeholders. Upstream copyright and MIT/Apache attribution are retained. Metadata does not imply Developer ID signing or Apple notarization.
