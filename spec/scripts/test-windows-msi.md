# Actual MSI install and uninstall smoke test

`scripts/test-windows-msi.ps1` requires Windows and PowerShell 7. Mandatory MsiPath and SourceDirectory identify the built MSI and original extracted portable payload. Optional LogDirectory defaults to dist/msi-test-logs. Each run preserves uniquely named verbose install/uninstall logs and a PowerShell smoke transcript; it does not delete logs.

The test refuses to proceed if the expected per-user installation directory, application Start Menu folder or matching HKCU Apps uninstall registration already exists. All seven expected source files must exist. This protects an existing user's installation and data from modification. The test does not require or run Rust or the graphical editor.

It runs actual msiexec installation with /i, /qn, /norestart and /L*v. Install and uninstall have a five-minute wait bound and accept only exit codes 0 and 3010; other codes fail with a log location. After successful installation it checks every expected installed file against its original source SHA-256, copies the installed shortcut unchanged into the preserved logs and loads the original Chinese path through Unicode IPersistFile.Load and IShellLinkW (not WScript.Shell.CreateShortcut, which returned empty properties on the hosted runner). Native load errors and empty paths fail rather than falling back to expected values. It verifies the shortcut target and working directory using normalized absolute paths, case-insensitive Windows equality and trailing-directory-separator normalization (logging both native paths), verifies per-user Apps registration with effective MSI version 0.2.2 (or its full authoring string 0.2.2.1) and an uninstall command, logging the exact registration; Windows Installer encodes only the first three version fields, then invokes the existing test-windows-mcp script against the installed op-mcp.exe for initialize and tools/list.

A finally block always uninstalls after a successful installation, even when hash, shortcut, registry or MCP validation fails. An unsuccessful install is left to MSI's rollback mechanism and its preserved diagnostic log; the script does not blindly uninstall an unconfirmed product. Actual msiexec /x uses its own verbose log. The test asserts all packaged files, the shortcut/application Start Menu folder and Apps registration disappear. It never recursively deletes installation folders or user files. This test establishes actual package installation and MCP protocol behavior, not full UI/rendering acceptance, upgrade-path testing or Windows code-signing trust.
