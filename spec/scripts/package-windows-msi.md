# MSI packaging from verified portable files

`scripts/package-windows-msi.ps1` requires Windows, PowerShell 7 and the preinstalled pinned WiX dotnet tool version 4.0.6. It takes mandatory SourceDirectory and optional OutputDirectory (default dist, relative to the caller's directory). SourceDirectory is the root payload directory extracted from an independently verified Windows ZIP; the script does not itself authenticate or download that ZIP, install tools or invoke Rust.

Before building, it requires both executables, the Chinese usage document and all four license files as nonempty files. It checks `wix --version` is exactly 4.0.6, allowing build metadata. It builds the authored installer with x64 architecture, PackageSource set to the resolved payload directory and ProductVersion set to 0.2.2.1. WiX failures stop execution.

The output is OpenPhoto-0.2.2.1-zh-CN-windows-x64.msi plus a .msi.sha256 sidecar containing the lowercase SHA-256 and MSI basename, encoded UTF-8 without BOM. Existing MSI, checksum or corresponding wixpdb outputs cause a refusal rather than replacement. A nonempty MSI must exist before hashing. Debug symbols generated by WiX are not part of the distributed payload. No signing, installation, GPU testing or claims of graphical acceptance occur in this builder.
